# Testing

Run `python3 -m unittest discover -s tests -v` for thirteen local tests covering streaming, persistence, owner isolation, token denial, provider restrictions, configuration, deletion, retention, investigation evidence, policy proposals, alert delivery, and the model tool protocol. The policy test uses a fake verifier to confirm that staging does not change the active file. On a Wazuh host, run a candidate through native `verify-agent-conf` before considering deployment. Test the SSH rule with all three fixtures using native `wazuh-logtest` before manager restart.

Build the native plugin with esbuild 0.25.12. With `ESBUILD_PATH` set to that installation's JavaScript API, run `node tests/test_read_tools.js` to check source allowlists, argument bounds, and permission propagation, then `node tests/test_chat_broker.js` to exercise a complete tool call, current-user search, audit record, and saved reply through a fake loopback model service. The broker test requires permission to bind local port 8765.

On the test host, a loopback smoke test using the configured provider produced a `get_capabilities` call and a complete answer after the tool result, then produced a `search_alerts` call for a recent SSH-login question. This verifies provider tool support, not the authenticated Wazuh search path. Check a real search and the chat UI in an operator-owned authenticated session without browser automation.
