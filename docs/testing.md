`python3 -m unittest discover -s tests -v` passes ten local tests covering SSE streaming, persistence, cross-user isolation, token denial, provider restrictions, configuration, deletion, retention, investigation evidence, and policy proposal generation. The policy test uses a fake verifier to check that a temporary candidate is tested without changing the active file. On an installed Wazuh host, also run a candidate through the real `verify-agent-conf` command. The native bundle builds with esbuild 0.25.12. An authenticated Dashboard browser session is needed for end-to-end UI testing.
